# Installation

## Composer

```shell
composer require divengine/ajaxmap
```

## Manual

Clone the repository and include the source files:

```shell
git clone https://github.com/divengine/ajaxmap
```

```php
<?php

require '/path/to/ajaxmap/src/ajaxmap.php';
```

The client library is located at `src/ajaxmap.js`. You can serve it yourself or
use the built-in `?lib` endpoint from your server script.
